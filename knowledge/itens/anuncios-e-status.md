# Anúncios e estados dos itens

Cada item possui título, descrição, tipo, imagens, `minInitialBid` (valor mínimo inicial), `minBidIncrement` (incremento mínimo), `bidDeadline` (prazo de encerramento), `paymentDeadlineDays` (prazo de pagamento em dias), status e datas de criação/atualização.

| Código             | Rótulo               |
| ------------------ | -------------------- |
| `draft`            | Rascunho             |
| `active`           | Em leilão            |
| `closed`           | Encerrado            |
| `awaiting_payment` | Aguardando pagamento |
| `paid`             | Pago                 |
| `cancelled`        | Cancelado            |

A página pública não expõe indiscriminadamente todos os itens; rascunhos, encerrados e cancelados não devem ser tratados como anúncios públicos disponíveis. Não invente título, valor, número de lances, maior lance, prazo restante ou status específico. Consulte a página ou uma ferramenta autorizada.
