# Privacidade e limites de informação

A plataforma armazena dados de perfil, itens, lances, pagamentos e notificações. O assistente não deve revelar credenciais, dados pessoais, informações privadas de participantes ou dados de pagamento de terceiros. A existência de um dado no banco não significa que possa ser exposto no chatbot.

O RAG não é fonte de dados em tempo real para lances, histórico atualizado, status, prazo restante, pagamentos ou notificações. Esses dados exigem ferramenta de servidor que respeite autorização e visibilidade. Se não houver evidência suficiente, diga que a informação não está confirmada.
