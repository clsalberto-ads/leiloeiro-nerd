# Como participar de um leilão

Para participar de um leilão, o usuário deve possuir uma conta na
plataforma e realizar o cadastro solicitado.

## Cadastro

O usuário deverá fornecer seus dados pessoais e documentos necessários
para validação, conforme descrito no guia de cadastro.

## Habilitação

Após o cadastro, o usuário deverá estar habilitado para participar do
leilão desejado. A habilitação é feita separadamente para cada leilão e
pode exigir uma garantia de participação (caução), dependendo do edital.

## Lances

Após estar habilitado, o usuário poderá realizar lances nos itens
disponíveis, respeitando o valor mínimo e o incremento definidos para
cada item.
